### Hi, I'm José 👋

I'm cofounder and CEO of [Vitrina](https://vitrinadev.com), from Santiago, Chile.

Vitrina is the AI platform where a small business lives. The chats, the customers, the stock, the calendar, the website and the invoices, all in one place. On top of that, an AI that answers WhatsApp, Instagram and email with the real data. So it quotes the car that's actually in stock and books the slot that's actually free.

We started with car dealerships. Now clinics too. It's Francisco and me, no employees, and a lot of agents running in parallel.

### How I got here

Almost everything I've built started the same way. I use something, I hit a wall, and I'd rather build the fix than wait for someone else to.

At SoyMomo I built a WhatsApp sales agent in 2024. That code turned into Vitrina.

At Connect, my fundraising company, I got tired of doing commissions in spreadsheets, so I built the ERP. Then I got tired of doing taxes by hand, so I built an invoicing API for the SII.

I also sell iPhones at [MacPhones](https://macphones.cl), and the store runs on Vitrina. If something breaks, I'm the first one to know.
